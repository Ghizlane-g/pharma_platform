# Pharma Platform

Plateforme de gestion pharmaceutique développée dans le cadre d'un stage.

## Technologies

- Python
- Django
- Django REST Framework
- HTML / CSS
- SQLite
- JWT
- Docker
- Docker Compose

## Architecture

Le projet est composé de deux parties :

- Backend : API REST avec Django REST Framework
- Frontend : interface web avec Django

## Fonctionnalités

- Authentification
- Gestion des comptes
- Gestion des acheteurs
- Gestion des clients
- Gestion des médicaments
- Gestion du stock
- Panier
- Commandes
